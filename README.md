# 🎨 Obsidian优雅仪表板模板

一个功能丰富、设计优美的Obsidian仪表板，包含笔记活动可视化、番茄时钟、项目管理、任务追踪等功能。

**特色亮点** ✨

- 📊 **笔记活动追踪** - 年月周三视图，展示你的写作热力图
- ⏱️ **番茄时钟** - 倒计时和累加两种模式，记录专注时间
- 🎯 **项目管理** - 快速添加、编辑、删除项目，显示优先级和进度
- 📋 **任务管理** - 今日任务、待办任务、已完成任务的分类显示
- 📈 **数据统计** - 实时显示笔记数量、字数、链接数等数据
- 🌍 **多语言支持** - 中文/英文一键切换
- 🌙 **主题自适应** - 浅色/深色主题自动适配，协调的绿色配色

## 📦 安装方法

### 1. 复制文件
将 `Homepage.md` 复制到你的Obsidian仓库的 `Dashboard` 文件夹中。

```
你的Obsidian仓库/
├── Dashboard/
│   └── Homepage.md
```

### 2. 创建必要文件夹结构
```
Dashboard/
├── Homepage.md
├── Project List.md
└── Todo List.md

Projects/
├── (项目文件)
```

### 3. 设置项目数据
在 `Dashboard/Project List.md` 中添加YAML格式的项目数据：

```yaml
---
tags: project-list
projects:
  - name: 项目名称
    status: active
    priority: high
    progress: 50
---
```

### 4. 在主页创建链接
在你的Obsidian主页（或任何地方）创建一个链接指向 `Homepage.md`：

```markdown
[[Dashboard/Homepage.md|📊 仪表板]]
```

## 🎮 功能说明

### 笔记活动卡片
- **年视图**：最近365天的写作热力图
- **月视图**：当月详细日历
- **周视图**：最近7天详情
- 自动统计活跃日、文件活动、新增笔记

### 番茄时钟
- 支持自定义专注时间（1-180分钟）
- 倒计时模式：固定时长专注
- 累加模式：灵活记录任意长度专注
- 自动保存每日专注时间到localStorage
- 实时显示今日和本月统计

### 项目管理
- 快速添加/编辑/删除项目
- 支持4种状态：规划中、进行中、暂停、已完成
- 3个优先级：低、中、高
- 进度条可视化（0-100%）
- 关联笔记功能

### 任务管理
- 三分类显示：今日、待办、已完成
- 自动识别高优先级任务（#priority/high标签）
- 固定任务（📌符号）显示在最前
- 实时统计今日、本周、本月完成情况

### 数据统计
- 笔记总数
- 全库字数统计
- 链接总数
- 最近12个月字数趋势（柱状图）
- 标签分布（甜甜圈图）

## 🎨 配色方案

- **浅色主题**：柔和的绿色渐变
  - 浅绿：`rgba(154, 208, 180, ...)`
  - 中绿：`rgba(93, 167, 110, ...)`

- **深色主题**：深邃的绿色
  - 浅绿：`rgba(130, 190, 160, ...)`
  - 深绿：`rgba(65, 140, 90, ...)`

## 🌍 多语言切换

点击右上角的"中 / En"按钮即可在中英文之间切换。

## 📝 任务格式

在你的任务文件中使用以下格式：

```markdown
- [x] 任务名称 📌 #priority/high #tag1 #tag2 ✅ 2026-08-26
- [ ] 待完成任务
```

- `[x]` 表示已完成，`[ ]` 表示未完成
- `📌` 表示固定（会显示在最前）
- `#priority/high` 表示高优先级
- `✅ YYYY-MM-DD` 表示完成日期
- 其他 `#标签` 会自动识别

## 🔧 自定义

### 修改配色
编辑 `Homepage.md` 中的颜色值：
- 搜索 `rgba(154, 208, 180` 替换为你喜欢的颜色

### 修改番茄时钟默认时间
在番茄时钟代码块中修改 `DEFAULT_FOCUS_TIME`

### 修改任务目标值
在任务统计部分修改：
```javascript
var todayTarget = 5, weekTarget = 25, monthTarget = 100;
```

## 🐛 常见问题

**Q: 图表不显示？**
A: 确保网络连接正常，Chart.js CDN可以正常加载。

**Q: 数据没有保存？**
A: 确保浏览器允许localStorage，且没有清除浏览数据。

**Q: 任务没有识别？**
A: 检查任务格式是否正确，确保使用 `✅ YYYY-MM-DD` 格式记录完成日期。
